# Cubemancy

Prototype iPhone: monde voxel 3e personne (style Cube World). Ouvre `index.html` dans Safari / Chrome, ou https://jprivard-baam.github.io/mage-duel/

## Contrôles
- **iPhone:** joystick gauche (marcher), glisser à droite (regarder), Saut, Frapper, Feu / Glace / Foudre
- **Bureau:** WASD ou ZQSD, souris (clic pour lock), Espace, F, 1/2/3

## Survie
Île de terre, roche et arbres. Inventaire Bois: frappe un arbre pour le transformer en bois. La faim baisse. La nuit, des loups et des slimes apparaissent. PV 0 → *Vous êtes mort*.

Le bot codeur s’appelle Mage Duel. Le jeu s’appelle Cubemancy.
